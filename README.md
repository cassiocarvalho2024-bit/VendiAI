# 🤖 VendiAI - Assistente de Vendas com IA

Ganhe dinheiro criando conteúdo de venda automaticamente com IA! 💰

## 📋 Sobre o Projeto

**VendiAI** é uma aplicação SaaS que usa **IA (OpenAI)** para gerar automaticamente:
- 📱 Mensagens de venda para WhatsApp/Instagram
- 💼 Propostas e orçamentos profissionais
- 📸 Posts para redes sociais
- 📧 Emails de venda convincentes

Perfeito para **autônomos, consultores, pequenas empresas** que querem **vender mais em menos tempo**.

---

## 🚀 Recursos Principais

✅ **Gerador de Conteúdo com IA** - Crie textos em segundos
✅ **Planos Flexíveis** - Free, Starter, Pro, Enterprise
✅ **Histórico de Gerações** - Guarde tudo que criou
✅ **Interface Intuitiva** - Fácil de usar para qualquer um
✅ **Suporte a Múltiplos Formatos** - Mensagens, propostas, posts, emails
✅ **Sistema de Autenticação** - Contas seguras com hash de senha
✅ **Banco de Dados** - Salva tudo que você cria

---

## 🛠️ Tecnologias Usadas

- **Backend:** Flask (Python)
- **Frontend:** HTML5, CSS3, JavaScript vanilla
- **Banco de Dados:** SQLite
- **IA:** OpenAI API (GPT-3.5-turbo)
- **Autenticação:** Werkzeug (hash de senha)
- **ORM:** SQLAlchemy
